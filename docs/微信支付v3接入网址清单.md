## 二、微信官方站点

### 2.1 后台管理

| 网址 | 用途 |
| --- | --- |
| `https://pay.weixin.qq.com` | **商户平台**：修改 Native 回调链接、AppID 账号管理、查看产品权限 |
| `https://mp.weixin.qq.com` | **小程序后台**：查看微信认证状态、确认微信支付授权 |

商户平台关键路径：

- 产品中心 → 开发配置 → Native支付回调链接
- 产品中心 → AppID账号管理 → 关联 AppID
- 账户中心 → API安全 → APIv3 密钥 / 微信支付公钥

### 2.2 开放平台（下一步）

| 网址 | 用途 |
| --- | --- |
| `https://open.weixin.qq.com` | **开放平台**：注册网站应用，获取支付用 AppID |

办理路径：

1. 管理中心 → 开发者资质认证（300 元/年）
2. 管理中心 → 网站应用 → 创建
   - 网站地址：`https://www.rabbitj.top`
   - 授权回调域：`www.rabbitj.top`
3. 审核通过后获得 `AppID`（`AppSecret` 本项目用不到）
4. 商户平台关联该 AppID → 开放平台确认授权

> 主体必须与商户号主体一致，否则绑定时报「主体不符」。
